# SCT_DS_4
# Traffic Accident Data Analysis

## Task 4 - Traffic Accident Pattern Analysis

### Objective

Analyze traffic accident data to identify patterns and contributing factors using data visualization and exploratory data analysis techniques.

## Dataset

The project uses the Car Crashes dataset from the Seaborn dataset repository.

Dataset Source:
https://raw.githubusercontent.com/mwaskom/seaborn-data/master/car_crashes.csv

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## Project Workflow

### Data Loading

* Loaded the dataset directly from an online source using Pandas.
* Inspected the dataset structure and data types.

### Data Exploration

* Checked dataset information using `df.info()`.
* Verified the absence of missing values.

### Visualizations Created

#### 1. Speeding Distribution

* Analyzed the distribution of accidents related to speeding using a histogram.

#### 2. Alcohol vs Speeding Analysis

* Created a scatter plot to examine the relationship between alcohol involvement and speeding-related accidents.

#### 3. Correlation Heatmap

* Visualized correlations among numerical variables to identify strong relationships between accident factors.

#### 4. Top States by Total Accidents

* Identified and visualized states with the highest accident counts using a bar chart.

## Key Insights

* Speeding is a significant factor in traffic accidents.
* Alcohol involvement shows a positive relationship with speeding-related crashes.
* Several accident-related variables exhibit strong correlations.
* Certain states report higher accident frequencies than others.
